Users and groups from Microsoft Entra ID (SCIM provisioning)

Provisioning from Microsoft Entra ID sends all users of the groups assigned to the provisioning app – including people who never signed in, so that they are notified, too – and updates them and the group members about every 40 minutes.

Sign-in updates the groups of the user who signs in from the groups claim. This works with any OpenID Connect provider, but only for people who have signed in. The members of provisioned groups are left to provisioning.

Tenant URL {{.Sync.TenantURL}} In the Microsoft Entra admin center create an enterprise application for provisioning (the app registration of single sign-on cannot provision): Create your own application → Non-gallery if Entra ID can reach this address from the internet (HTTPS with a publicly trusted certificate), otherwise the On-premises SCIM app with the Microsoft Entra provisioning agent. Under Provisioning choose the mode Automatic, enter this Tenant URL and the token as Secret Token, then assign the groups to the application and start provisioning. {{- if not .St.BaseURL}} The address is derived from this page – set the base URL above so that it does not change.{{end}}
