The ID token claim that lists the user's groups; default groups.
Microsoft Entra ID puts the object IDs of the groups into the groups claim, not their names. With this option the status page reads the names with Microsoft Graph – shortly after a sign-in records a new group, and once a day so that renamed groups follow – and shows them in Admin → Groups and wherever groups are listed. It uses this app registration, which needs the Microsoft Graph application permission GroupMember.Read.All with admin consent. {{template "field-error" .Errors.entra_group_names}}
Users whose roles claim contains one of the app roles below get that role, in addition to the roles of their groups. In Microsoft Entra ID, create these app roles in the app registration (App roles) and assign users or groups to them in its enterprise application (Users and groups). A change of the assignments applies at the user's next sign-in.
