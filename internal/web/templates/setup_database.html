Database
SQLite needs no installation and is the right choice for most installations. Use PostgreSQL if you already run it and want the data on a database server.

The database must already exist and the user must be allowed to create tables in it (being the owner of the database is enough).

prefer encrypts if the server supports it; require always encrypts; verify-full also checks the server certificate.
Leave empty to use {{.DefaultSQLitePath}}. Relative paths are relative to the data folder.
